# LF3 Advocacia

Site estático recuperado do backup da Hostinger de 03/11/2026.

## Publicação

GitHub Actions e GitHub Pages estão desativados por solicitação do responsável. Não habilitar workflows, Actions ou Pages. A hospedagem pública alternativa ainda depende de definição; o repositório guarda os arquivos preparados para publicação.

## Conteúdo

- 21 páginas legítimas recuperadas, incluindo páginas institucionais, 10 artigos jurídicos e a página de investimento imobiliário.
- Imagens, fontes e estilos locais preservados a partir das referências das páginas.
- Sete formulários adaptados para abrir o WhatsApp do escritório com a mensagem preenchida. O visitante revisa e envia no WhatsApp.
- Menu móvel e controles de expansão independentes de WordPress.
- Tags Google e widget Jivo originais preservados a partir dos endereços identificados no site.

## Preservação e limites

O WordPress, plugins executáveis, credenciais e bancos de dados não fazem parte deste repositório. O backup original foi preservado localmente. Foram identificadas no backup publicações de downloads/filmes sem relação com a advocacia; elas foram excluídas desta versão estática por seleção explícita das páginas legítimas. Isso não constitui uma auditoria completa do WordPress original.

O painel administrativo WordPress não funciona nesta versão estática. Alterações futuras de conteúdo precisam ser feitas nos arquivos ou em outro sistema de edição. Os registros de e-mail da Hostinger não foram modificados.

## Verificação realizada

- Referências locais de HTML e CSS verificadas sem arquivos ausentes.
- Nenhum arquivo PHP, SQL, arquivo de ambiente ou backup incluído.
- Página inicial, página imobiliária e formulário conferidos no navegador interno.
- Menu móvel testado em largura de 390 pixels.
- Formulário abriu o destinatário e a mensagem esperados no WhatsApp, sem envio de mensagem.
- Disponibilidade pública no domínio original ainda não validada.
